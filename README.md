HiBinds

Локальный менеджер биндов и быстрых действий для Windows

Создавайте собственные бинды, объединяйте действия в сценарии и запускайте их одной кнопкой — локально, быстро и без облака.

О проекте

HiBinds — desktop-приложение для Windows, предназначенное для создания и запуска пользовательских биндов.

Один бинд может содержать горячую клавишу и последовательность действий. Это позволяет запускать программы, открывать сайты и собирать простые сценарии из нескольких шагов без необходимости выполнять каждое действие вручную.

Основная идея проекта — сделать управление повседневными действиями быстрым, локальным и понятным.

Возможности

Бинды

HiBinds позволяет создавать собственные бинды с названием и горячей клавишей.

Каждый бинд может содержать несколько последовательных действий:

ГОРЯЧАЯ КЛАВИША
        ↓
     ДЕЙСТВИЕ
        ↓
     ЗАДЕРЖКА
        ↓
     ДЕЙСТВИЕ
        ↓
     ЗАДЕРЖКА
        ↓
     ДЕЙСТВИЕ

Поддерживаемые действия

В текущей версии доступны:

запуск .exe файлов;

открытие URL через системный браузер;

задержки между действиями;

последовательное выполнение нескольких действий;

остановка выполняемого сценария.

Пример:

F6
 ↓
Запустить Discord.exe
 ↓
Подождать 500 мс
 ↓
Открыть https://discord.com

Проверка конфигурации

HiBinds автоматически проверяет сохранённые бинды и помогает найти проблемы до запуска.

Проверяются:

корректность структуры базы;

наличие действий у бинда;

корректность горячих клавиш;

дубликаты горячих клавиш;

корректность задержек;

корректность URL;

существование указанных .exe файлов;

неизвестные или повреждённые типы действий;

повторяющиеся действия внутри одного бинда.

Результат проверки разделяется на рабочие бинды и конфигурации, которые требуют внимания.

Пример:

✓ 12 биндов работают
⚠ 2 требуют внимания

Импорт и экспорт

Для переноса конфигурации между компьютерами используется собственный формат:

.hibinds

Экспорт содержит:

формат файла;

версию формата;

название приложения;

дату экспорта;

сохранённые бинды.

Также HiBinds умеет импортировать .hibinds и совместимые JSON-файлы.

Локальное хранение данных

Пользовательские данные не хранятся внутри исполняемого файла.

На Windows используется:

%APPDATA%\\HiBinds

Основные файлы:

%APPDATA%\\HiBinds\\
├── HIBinds.json
└── settings.json

Это позволяет свободно переносить HiBinds.exe между папками и при этом хранить пользовательскую конфигурацию отдельно.

Восстановление старых баз

Проект поддерживает автоматический поиск старых файлов базы, в том числе:

HIBinds.json
HIbinds.json

Если основная база повреждена, HiBinds сохраняет резервную копию повреждённого файла перед созданием новой пустой базы.

Запуск вместе с Windows

В настройках приложения можно включить автоматический запуск HiBinds вместе с Windows.

Для Windows используется пользовательская ветка реестра:

HKEY_CURRENT_USER
\\Software
\\Microsoft
\\Windows
\\CurrentVersion
\\Run

Настройка не требует установки отдельной службы Windows.

Интерфейс

HiBinds построен как desktop-приложение с акцентом на тёмный интерфейс, крупную типографику и быстрый доступ к основным действиям.

Основные разделы приложения:

┌──────────────────────────────┐
│           HiBinds             │
├──────────────┬───────────────┤
│ Обзор        │               │
│ Мои бинды    │  Рабочая      │
│ Создать      │  область      │
│ Настройки    │               │
└──────────────┴───────────────┘

Основные элементы интерфейса включают:

обзор состояния конфигурации;

список сохранённых биндов;

редактор нового бинда;

настройки приложения;

импорт и экспорт конфигурации;

запуск и остановку действий;

журнал выполнения.

Интерфейс создан на базе CustomTkinter поверх стандартного Tkinter.

Выполнение сценариев

Запуск бинда выполняется в отдельном рабочем потоке, поэтому GUI не должен блокироваться во время выполнения задержек и внешних процессов.

Схема выполнения:

HiBinds GUI
     │
     ▼
Выбор бинда
     │
     ▼
Worker Thread
     │
     ├── действие 1
     │
     ├── задержка
     │
     ├── действие 2
     │
     └── действие 3

Для передачи сообщений в интерфейс используется очередь сообщений, что позволяет безопасно обновлять журнал выполнения из рабочего потока.

Основные файлы

src/app.py

Главная точка приложения.

Отвечает за:

графический интерфейс;

загрузку и сохранение биндов;

работу с настройками;

проверку конфигурации;

создание и редактирование биндов;

запуск действий;

остановку выполнения;

импорт и экспорт;

автозапуск Windows;

журнал выполнения.

src/bootstrap.py

Вспомогательный загрузчик зависимостей для запуска проекта из исходников.

При отсутствии customtkinter выполняется установка необходимой зависимости через pip.

src/migrate_legacy.py

Отвечает за работу со старыми вариантами хранения базы и поддержку legacy-конфигураций.

build.py

Основной Python-сборщик проекта.

Использует PyInstaller и собирает приложение в один файл:

HiBinds.exe

Готовый .exe создаётся непосредственно в корне проекта.

build_windows.bat

Windows-скрипт, который:

находит Python;

проверяет pip;

устанавливает необходимые инструменты сборки;

запускает build.py;

проверяет наличие итогового HiBinds.exe.

START_BUILD.cmd

Простой дополнительный launcher для build_windows.bat.

requirements.txt

Содержит зависимости проекта:

customtkinter>=5.2.2,<6

Технологии

Python 3 — основной язык проекта;

Tkinter — базовый GUI toolkit;

CustomTkinter — современный слой интерфейса;

PyInstaller — сборка Windows EXE;

JSON — локальное хранение биндов и настроек;

Windows Registry — пользовательский автозапуск;

Threading / Queue — выполнение сценариев без блокировки интерфейса.

Проект рассчитан на локальную работу в Windows и не требует отдельного сервера или базы данных.

Запуск из исходников

Убедитесь, что установлен Python 3.11 или новее.

Установите зависимости:

pip install -r requirements.txt

Запустите приложение:

python src/app.py

При необходимости bootstrap.py может установить отсутствующую зависимость customtkinter автоматически.

Сборка EXE

Для Windows можно использовать готовый скрипт:

build_windows.bat

После завершения сборки в корне проекта должен появиться:

HiBinds.exe

Файл является standalone-сборкой и предназначен для запуска без установленного Python-интерпретатора на целевой машине.

Также проект содержит GitHub Actions workflow для автоматической сборки Windows-версии.

Безопасность и ответственность

HiBinds запускает программы и открывает адреса от имени текущего пользователя Windows.

Перед сохранением бинда рекомендуется проверить:

путь к запускаемому .exe;

адрес URL;

последовательность действий;

установленные задержки;

необходимость запуска приложения с текущими правами пользователя.

HiBinds предназначен для локальной автоматизации и не требует передачи конфигурации на внешний сервер.
