# HiBinds

Современный менеджер последовательных запусков программ и URL.

## Возможности

- Запуск сохранённых биндов.
- Добавление нескольких действий в один бинд.
- Проверка файлов и URL перед запуском.
- Автоматическая диагностика базы при старте.
- Импорт и экспорт в `.hibinds`.
- Поиск по биндам.
- Проверка горячих клавиш и дубликатов.
- Автозапуск вместе с Windows.
- Тёмная / светлая / системная тема.
- Данные в `%APPDATA%\\HiBinds`.
- Сборка в один `HiBinds.exe`.

## Сборка Windows EXE

1. Распакуй архив целиком.
2. Запусти `build_windows.bat`.
3. После успешной сборки `HiBinds.exe` появится прямо в корне проекта.
4. Готовый `.exe` можно перенести на рабочий стол отдельно от исходников.
